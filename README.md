# Pro Merchant Savings — Website

Conversion-focused marketing site for **Pro Merchant Savings**, an independent merchant services
consultancy that helps small and mid-sized businesses lower credit card processing costs.

- **Phone (click-to-call):** [(614) 419-1601](tel:+16144191601)
- **Email:** [promerchantsavings@gmail.com](mailto:promerchantsavings@gmail.com)

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies, no external APIs.
Open `index.html` in a browser or serve the folder statically (e.g. `python3 -m http.server`).

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Hero + CTA, services overview, process, why us, reviews, FAQ, quote form |
| `services.html` | Detailed services and industries served |
| `about.html` | Approach, promises, transparency on compensation, full reviews |
| `faq.html` | Full FAQ grouped by pricing, programs, setup and support (FAQPage schema) |
| `contact.html` | Contact details, hours, service area and the quote request form |

## Structure

- The quote form is fully client-side validated and composes a pre-filled email to

- Sticky click-to-call bar on mobile; the phone number also appears in the top bar, hero, footer and CTAs.
- Semantic HTML, skip link, ARIA labels, reduced-motion support and print styles included.
