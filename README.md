Build a modern, professional multi-page website for **Beacon Payments** — a local credit card processing solutions provider operated by **John Jenkins** in **Dublin, Ohio**. The site should feel trustworthy, personal, and conversion-focused — not corporate or templated.

---

## GLOBAL DESIGN DIRECTION

**Color Palette:**
- Primary: Deep blue (#0F3460)
- Secondary: Black (#1A1A2E)
- Accent: White (#FFFFFF)
- Subtle accent: Light blue (#E8EFF7) for section backgrounds
- CTA buttons: Bright blue (#2563EB) with white text — high contrast, impossible to miss

**Typography:**
- Headlines: Inter or Plus Jakarta Sans — bold, clean, modern
- Body: Inter or system sans-serif — 16-18px for readability
- Keep it tight. Short paragraphs. Lots of white space.

**Design Vibe:**
- Clean, modern, trust-heavy — think Stripe meets a local service business
- Blue, white, and black palette throughout — NO random accent colors
- Sections should alternate between white and light blue/gray backgrounds for rhythm
- Subtle scroll animations on section entry (fade-up, nothing flashy)
- Placeholder image slots for John's headshot and business photos (use placeholder boxes with labels like "[John's Headshot]" and "[Team/Office Photo]")
- Mobile-first responsive design
- Sticky header with navigation + CTA button always visible

**Navigation:**
- Sticky top nav: Logo (left), nav links (center), "Free Savings Analysis" CTA button (right)
- Pages: Home, Services, About, Contact
- Mobile: hamburger menu

## TECHNICAL NOTES

- Build with React + Tailwind CSS
- Use React Router for multi-page navigation
- Responsive: mobile-first, hamburger nav on mobile
- Smooth scroll between sections on home page
- Add subtle fade-in animations on scroll (intersection observer)
- Calendar embed: use an iframe placeholder with a comment noting the GHL calendar URL will be inserted
- Contact form: Form embed
- SEO: proper meta titles and descriptions per page, semantic HTML, alt text on all images
- Fast: lazy load images, minimal dependencies
- Accessibility: proper heading hierarchy, focus states, alt text, ARIA labels
